# Getting Started

Welcome to Lone Format! This guide will help you get started with our Vue 3 component library.

## What is Lone Format?

Lone Format is a modern Vue 3 component library designed for formatting content with support for:

- **Tree-shaking**: Import only the components you need
- **TypeScript**: Full type safety and IntelliSense support
- **Modern Design**: Clean and customizable components
- **Easy Integration**: Simple setup and usage
