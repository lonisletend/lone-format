# Installation

## NPM

```bash
npm install lone-format
```

## Yarn

```bash
yarn add lone-format
```

## PNPM

```bash
pnpm add lone-format
```

## CDN

You can also use lone-format via CDN:

```html
<script src="https://unpkg.com/lone-format@latest/dist/lone-format.umd.cjs"></script>
```

## Requirements

- Vue 3.0+
- Node.js 16+
